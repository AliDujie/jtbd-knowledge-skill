# Contributing to JTBD Knowledge Skill

Thank you for your interest in contributing! This skill provides a comprehensive toolkit for Jobs to Be Done theory and practice.

## How to Contribute

### 📚 Content Contributions

- **Add new JTBD tools**: Opportunity score calculators, progress matrices
- **Improve method descriptions**: Clarify usage scenarios, prerequisites, or outputs
- **Add real-world examples**: Practical case studies for JTBD interviews and analysis
- **Translate content**: Help make this skill accessible in more languages

### 🔧 Code Contributions

- **Fix bugs**: Report and fix issues in the `jtbd/` module
- **Add features**: New analysis tools, opportunity framework enhancements
- **Improve performance**: Optimize opportunity score calculations
- **Add tests**: Ensure reliability of the toolkit

### 📝 Documentation

- **Improve README**: Clearer instructions, better examples
- **Add tutorials**: Step-by-step guides for JTBD interview process
- **Update references**: Keep JTBD frameworks current and accurate

## Development Setup

```bash
# Clone the repository
git clone https://github.com/AliDujie/jtbd-knowledge-skill.git
cd jtbd-knowledge-skill

# Install in development mode
pip install -e ".[dev]"

# Run tests
pytest

# Lint code
ruff check .
```

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Run tests and linting
5. Commit with descriptive messages
6. Push to your fork and submit a PR

## Code Style

- Follow PEP 8 guidelines
- Use type hints for new code
- Add docstrings for all public functions
- Keep line length under 100 characters

## Questions?

Open an issue or reach out to the maintainers. We welcome all contributions!
