## 来源

基于 Alan Klement《When Coffee and Kale Compete》(HarperCollins, 2023)，整合四大 JTBD 学派：Klement（进步力量）、Ulwick（ODI）、Wunker（Jobs Atlas）、Kalbach（Job Stories）。
